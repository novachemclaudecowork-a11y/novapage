# content/legacy/

舊站的網址對照資料。**網站不顯示這裡的任何內容**，但轉址功能依賴它們，請勿刪除。

| 檔案 | 用途 |
|---|---|
| `legacy-urls.json` | 舊站每個網址對應到哪一項產品（以分類 m、子分類 m2、分頁序號 pg 為鍵） |
| `name-corrections.json` | 舊站的錯字對照，例如「TI布熱轉往印油墨」→「TI布熱轉印油墨」 |

`scripts/build-redirects.mjs` 會讀取這兩份資料，產生舊網址到新網址的轉址邏輯。
若刪除，Google 已收錄的舊連結會全部失效。

裡面仍留有已停售品項的名稱（例如筆墨水），那是為了讓這些舊網址能正確
導向所屬分類而不是變成錯誤頁面，並非網站上的產品資料。
