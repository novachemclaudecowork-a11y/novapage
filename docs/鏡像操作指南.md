# 鏡像操作指南：把現行網站完整抓下來

目的：把 `www.novananoinks.com.tw` 的所有前端檔案（HTML／CSS／JS／圖片）
完整下載到本機，再放進本儲存庫，供重建分析使用。

> ⚠️ 這個動作是**公開讀取貴公司自己的網站**，與一般訪客瀏覽無異，
> 不涉及入侵、不會影響對方主機運作，也不會動到任何資料。

---

## 方式 A：Windows 使用者（推薦 HTTrack，有圖形介面）

1. 下載並安裝 **WinHTTrack Website Copier**：<https://www.httrack.com/page/2/>
2. 開啟後選「下一步」→ 專案名稱填 `novananoinks`
3. 「網址」欄貼上：`https://www.novananoinks.com.tw/`
4. 「設定選項」→「爬行」分頁 → 將 **「遵守 robots.txt 規則」改為「不要遵守」**
5. 「設定選項」→「限制」分頁 → **最大鏡像深度留空（不限制）**
6. 開始，等待完成（此站規模不大，通常 5～20 分鐘）
7. 完成後把產生的資料夾整包壓縮

---

## 方式 B：Mac / Linux 使用者（wget 指令）

先確認有安裝 wget：

```bash
# Mac（需先安裝 Homebrew）
brew install wget
```

執行鏡像（會在目前目錄產生 `site-mirror/` 資料夾）：

```bash
wget --mirror \
     --page-requisites \
     --no-parent \
     --execute robots=off \
     --restrict-file-names=windows \
     --user-agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0 Safari/537.36" \
     --wait=1 --random-wait \
     --tries=3 --timeout=30 \
     --span-hosts \
     --domains=novananoinks.com.tw,www.novananoinks.com.tw \
     --directory-prefix=site-mirror \
     https://www.novananoinks.com.tw/
```

或直接執行本專案附的腳本：

```bash
bash scripts/mirror-site.sh
```

### 參數說明

| 參數 | 用途 |
|---|---|
| `--mirror` | 遞迴下載整站，不限深度 |
| `--page-requisites` | 一併抓取頁面所需的 CSS、JS、圖片 |
| `--execute robots=off` | 忽略 robots.txt（這是貴公司自己的網站） |
| `--wait=1 --random-wait` | 每次請求間隔約 1 秒，**避免造成對方主機負擔** |
| `--restrict-file-names=windows` | 讓含 `?` 的檔名在 Windows 上也能正常儲存 |
| `--span-hosts` + `--domains` | 允許跨 `www` 與非 `www` 兩個網域，但不外流到其他網站 |

> 註：本指令刻意**不使用** `--convert-links`，以保留 HTML 中的原始網址，
> 方便後續分析網站結構。若你想離線瀏覽檢查，可另外加上該參數再跑一次。

## 抓完之後：確認清單

請大致檢查 `site-mirror/` 裡面有沒有以下東西：

- [ ] `index.asp` 或 `index.html`（首頁）
- [ ] 多個 `view.asp?...` 或 `view.html?...`（產品明細頁）
- [ ] `inquiry_list.asp`（詢價車）
- [ ] 一個放 CSS 的資料夾（常見命名：`css/`、`style/`）
- [ ] 一個放圖片的資料夾（常見命名：`images/`、`img/`、`upload/`、`uploads/`）
- [ ] 產品照片數量看起來合理（對照官網上實際產品數）

### 做法二：若檔案太大（超過 100MB）

先看一下大小：

```bash
du -sh site-mirror
```

若過大，通常是圖片造成的。可以先只推 HTML 與 CSS，圖片另外處理：

```bash
# 只保留 html / css / js，先讓我分析結構
find site-mirror -type f \( -name "*.jpg" -o -name "*.png" -o -name "*.gif" \) -delete
```

## 常見問題

**Q：這樣抓會不會被對方發現或告我們？**
A：這與一般人用瀏覽器逐頁瀏覽貴公司網站沒有本質差別，只是自動化。
抓下來的是貴公司自己的公開內容。指令已加上延遲，不會對主機造成壓力。

**Q：抓到的 `.asp` 檔打得開嗎？**
A：可以。下載到的是伺服器**執行後產生的 HTML 結果**，不是 ASP 原始碼。
這正是我們需要的——版面與內容，而不是對方的程式邏輯。

**Q：會不會抓到重複的頁面？**
A：會。因為同一個產品有 `view.asp` 和 `view.html` 兩種網址，
且分頁參數 `pg` 會產生多種組合。這不影響分析，我會在重建時去除重複。
