> 分析日期：2026-09-20
> 分析對象：`site-mirror/`（33 MB，896 個檔案）

## 一、最重要的發現：原站是第三方 SaaS 套版系統

現行網站每一頁的 HTML 原始碼裡都帶著這兩行：

```html
<meta name="author" content="H3 B2B System [h3.com.tw]">
<meta name="application-name" content="H3 B2B System">
```

**這代表網站不是那間設計公司自己寫的**，而是架在一套叫「H3 B2B System」的
第三方商用套版系統上（供應商為 h3.com.tw）。設計公司的角色比較接近
**代理商／代操作者**，負責幫貴公司在這套系統的後台上架資料、調整版型。

### 這件事的三個意涵

1. **「不給原始碼」其實不是不願意，多半是給不出來。**
   那套程式的著作權屬於 H3，不屬於設計公司，他們沒有權利轉讓。
   繼續在這點上交涉不會有結果。

2. **貴公司每年付的錢，有一部分是這套系統的授權／代管費用。**
   建議核對合約與付款明細，確認費用結構。

3. **更確立了「重寫」是唯一正確的路。**
   就算拿到程式碼也不能用（授權不在貴公司），而自建新站之後，
   這筆年費可以完全省下來。

## 二、原站技術結構（已由鏡像確認）

先前由網址推測的判讀，現已獲得證實並補充：

| 項目 | 實際情況 |
|---|---|
| 平台 | H3 B2B System（第三方 SaaS 套版系統） |
| 後端 | Classic ASP / IIS，`.html` 與 `.aspx` 皆為偽靜態對應 |
| 前端 | jQuery 1.12.2 + bxSlider / flexslider / owlCarousel2 / jssor（四套輪播並存） |
| 響應式 | 有 RWD，使用 mmenu + responsive-nav + slidebars 三套行動選單 |
| 其他 | AOS 動畫、Font Awesome、Google 字型 Lato、Google 翻譯元件 |
| 主選單 | **圖片式選單**（`/webmenu/photo/1/s1.jpg`…），搭配 MM_swapImage 滑鼠替換 |
| 訪客計數 | 頁尾 `TOTAL:79168` |

> 技術上的觀察：同時載入四套輪播套件與三套行動選單，是套版系統為了
> 相容各種客戶版型而全部包進來的結果，實際上絕大多數並未使用。
> 這也是現行網站載入較慢的主因之一。新站不會有這個問題。
>
> 另外，主選單使用圖片而非文字，對 SEO 與後續維護都不利
> （改一個選單字要重做圖片）。新站會改為文字選單。

## 五、⚠️ 發現的資料品質問題（需貴公司確認）

### 問題一：40 筆產品中有 17 筆是重複資料

同一項產品在資料庫裡被重複建立了多次。這是舊系統為了讓產品同時出現在
不同子分類下，只好整筆複製一份的結果。

| 產品 | 重複次數 | 重複的 id |
|---|---|---|
| 刮刀／刮膠 | ×4 | 156, 165, 168, 170 |
| MPV 通用塑膠油墨 | ×3 | 120, 121, 131 |
| 油墨專用稀釋劑 | ×3 | 132, 144, 146 |
| 橡膠處理劑 | ×3 | 135, 143, 173 |
| PET 水轉自行車標油墨 | ×2 | 122, 123 |
| TI 布熱轉印油墨 | ×2 | 127, 128 |
| 其他資材 | ×2 | 155, 167 |
| 除鬼影劑 | ×2 | 157, 158 |
| 油墨專用手膏洗手膏 | ×2 | 159, 164 |
| 補邊劑 | ×2 | 161, 162 |
| 調墨刀／調油刀／攪拌刀／抹刀 | ×2 | 166, 169 |
| 消光膏 | ×2 | 174, 175 |

**影響：** 重複內容會被 Google 判定為 duplicate content，稀釋搜尋排名。
新站會改為「一項產品一個頁面，可同時歸屬多個分類」，
既解決 SEO 問題，日後改一次產品說明也不必改四個地方。

### 問題二：疑似錯字

- 產品 id 127 / 128 的標題為「TI布熱轉**往**印油墨」，
  但左側選單上寫的是「TI布熱轉**網**印油墨」。
  推測正確應為「TI 布熱轉**印**油墨」。**請貴公司確認正確名稱。**

### 問題三：選單有 32 個子分類，但實際只有 23 項產品

左側選單列出「防塞劑」「擦拭劑」「消泡劑/助劑」「脫脂劑」「剝膜粉/膏」
「單液型補強液」「鋁框接著膠」「感光乳劑」「芳香除墨劑」「PP 處理劑」
「SW 洗版劑」「BS 稀釋劑」「CP 通用色膏」「PU 彈性網印油墨」
「金銀漿、中細閃、螢光粉」等子分類，但點進去沒有對應的產品明細。

**請確認：** 這些是「有賣但網站上沒上架」，還是「已停售」？
如果是前者，新站正好可以一併補上；這些都是實際有在賣的品項，
不上架等於白白流失搜尋流量。
