# 如何把鏡像檔交給 Claude

抓完網站之後，要把檔案送回本儲存庫。以下由易到難排列，**選一個就好**。

---

## ⚠️ 先理解一件事

在 GitHub 網頁上登入（包含用 Google 帳號登入），**和 git 指令列的驗證是兩套獨立的東西**。

GitHub 自 2021 年 8 月起**不再接受密碼做 git 操作**。
如果你是用 Google 帳號註冊的，更是完全沒有 GitHub 密碼可用。

所以出現這個錯誤是正常的，不是你操作錯誤：

```
remote: Invalid username or token. Password authentication is not supported for Git operations.
fatal: Authentication failed
```

---

## 方案 A：完全不用 git，直接在對話中上傳（最省事）✅

如果只是要讓 Claude 分析網站結構，**圖片其實可以晚點再處理**。
把圖片剔除後，整包通常只有幾 MB，可以直接附加在對話訊息裡。

### Mac / Linux

```bash
# 1. 先完整備份（保留圖片，之後重建版面會用到）
cp -r site-mirror site-mirror-完整備份

# 2. 複製一份只留 HTML / CSS / JS 的輕量版
cp -r site-mirror site-mirror-輕量
find site-mirror-輕量 -type f \
  \( -iname "*.jpg" -o -iname "*.jpeg" -o -iname "*.png" -o -iname "*.gif" \
     -o -iname "*.webp" -o -iname "*.ico" -o -iname "*.svg" \
     -o -iname "*.pdf" -o -iname "*.mp4" -o -iname "*.swf" \) -delete

# 3. 壓縮
zip -r 網站結構.zip site-mirror-輕量
du -sh 網站結構.zip     # 確認大小，通常 1～10 MB
```

### Windows

1. 先把抓下來的資料夾**整個複製一份**當備份
2. 在複製出來的那份裡，用檔案總管搜尋框輸入 `*.jpg`，全選後刪除
3. 對 `*.png`、`*.gif`、`*.pdf` 重複一次
4. 對資料夾按右鍵 →「壓縮成 ZIP 檔案」

### 然後

把 ZIP 直接拖進對話視窗附加上傳即可。**完全不需要 git、不需要任何帳號設定。**

> 圖片之後再用方案 B 或 C 補上，或是直接提供產品照原始檔（品質更好）。

## 方案 B：GitHub Desktop（圖形介面，不用碰指令）

適合要把完整鏡像（含圖片）推上來的情況。

1. 下載安裝 **GitHub Desktop**：<https://desktop.github.com/>
2. 開啟後選 **Sign in to GitHub.com**
   → 會自動跳到瀏覽器完成授權（**用你現在登入的 Google 帳號授權即可，不必輸入密碼**）
3. 回到 GitHub Desktop → `File` → `Clone repository` → 選 `novachemclaudecowork-a11y/novapage`
4. 左上角分支選單 → 切換到 `claude/website-clone-assessment-x09jd5`
5. 在 clone 下來的資料夾裡執行鏡像（見 `鏡像操作指南.md`）
6. 回到 GitHub Desktop，左側會自動列出所有新檔案
7. 左下角填 commit 訊息（例如「加入現行網站鏡像檔」）→ 按 **Commit**
8. 按上方的 **Push origin**

## 方案 C：Personal Access Token（仍用指令列）

1. 登入 GitHub 網頁 → 右上角頭像 → **Settings**
2. 左側選單拉到最底 → **Developer settings**
3. **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
4. 設定：
   - Note：隨便填，例如 `novapage 上傳用`
   - Expiration：選 30 days 即可（用完就作廢，比較安全）
   - Select scopes：**只勾 `repo`** 這一項
5. 按 **Generate token** → **立刻複製產生的字串**（離開頁面後就再也看不到）
6. 執行 push 時，出現提示這樣填：
   - `Username:` → `novachemclaudecowork-a11y`
   - `Password:` → **貼上剛剛複製的 token**（不是密碼；畫面上不會顯示任何字元，這是正常的）

> 🔒 這個 token 等同帳號密碼，不要貼到聊天室、email 或任何文件裡。用完可回同一頁面按 Delete 作廢。

## 方案 D：GitHub CLI

若電腦上已有 `gh` 指令：

```bash
gh auth login
# 選 GitHub.com → HTTPS → Yes(用 git 憑證) → Login with a web browser
# 照畫面指示在瀏覽器完成授權即可
```

之後 `git push` 就會正常運作。

## 補充：clone 不需要驗證

本儲存庫是公開的，所以**下載不需要任何帳號設定**：

```bash
git clone https://github.com/novachemclaudecowork-a11y/novapage
```

只有 **push（上傳）** 才需要上述其中一種驗證方式。

若只是想拿 `scripts/mirror-site.sh` 這個腳本，也可以直接到網頁上按
「Download ZIP」下載，連 git 都不用裝。
