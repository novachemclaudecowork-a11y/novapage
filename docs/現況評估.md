# 現況評估：www.novananoinks.com.tw

> 評估日期：2026-09-19
> 對象：貝星貿易股份有限公司（NOVACHEM TRADING CO., LTD.）官方網站
> 目的：判斷是否能在不取得原廠商原始碼的前提下，由公司自主重建並運營此網站

---

## 一、結論（先講重點）

**可以。技術難度屬於低階，沒有任何無法取代的技術資產。**

現行網站是台灣中小企業常見的「套版型企業型錄網站」，使用約 2010 年前後的技術。
整站本質上只是「產品分類 → 產品列表 → 產品明細 → 詢價表單」，
不含金流、會員系統、庫存管理或任何複雜商業邏輯。

**但真正的風險不在程式碼，在網域與主機的所有權**（見 `接管檢查清單.md`）。

---

## 二、技術判讀

從公開索引到的實際網址反推：

```
/view.asp?id=132&m=2&m2=142&pd_type=142&pdid=sub2&pg=1
/view.html?id=133&m=2&m2=143&pd_type=143&pdid=sub2&pg=1
/inquiry_list.asp
```

| 項目 | 判讀結果 |
|---|---|
| 後端語言 | **Classic ASP**（`.asp`），執行於 Windows / IIS 主機 |
| 網址美化 | `.html` 為偽靜態（URL Rewrite），實際仍指向同一支 `view.asp` |
| 資料層 | 資料庫驅動（MS Access 或 MS SQL Server，為此類套版站慣例） |
| 網址參數 | `m` 主分類、`m2` 次分類、`pd_type` 產品類別、`id` 產品編號、`pg` 分頁 |
| 前端 | 傳統 HTML + CSS + jQuery（待鏡像後確認是否為 RWD 響應式） |

### 已辨識的功能模組

1. 首頁
2. 關於我們／公司簡介
3. 產品分類瀏覽（四大產品線）
4. 產品明細頁 `view.asp`
5. **詢價車 `inquiry_list.asp`** — 可累加多項產品後一次送出詢價
6. 聯絡我們 / 詢價表單

### 已辨識的產品線

- 網印油墨（MPV 通用塑膠油墨、PET 商標貼紙油墨、410 刮刮樂網印油墨、PU 彈性網印油墨、CW 水性油墨、色母等）
- 製版資材（高解度感光乳劑等）
- 筆墨水
- 洗版劑（洗版劑、油墨專用稀釋劑等）

## 三、哪些拿得到、哪些拿不到

### ✅ 拿得到（100%）

| 項目 | 說明 |
|---|---|
| 前端 HTML / CSS / JavaScript | 伺服器本來就會送到每位訪客的瀏覽器，公開可見 |
| 所有圖片、產品照、Logo | 同上 |
| 版面配置與視覺設計 | 可完整還原 |
| 全部產品資料 | 品名、規格、說明文字，可由全站爬取重建為資料庫 |
| 網站結構與導覽邏輯 | 由網址參數即可完整推導 |

### ❌ 拿不到

| 項目 | 影響評估 |
|---|---|
| `.asp` 後端原始碼 | **無影響**。Classic ASP 已是微軟停止發展的技術，取得反而是負債 |
| 後台管理程式（CMS） | **無影響**。新站會建立自己的內容管理方式 |
| 原始資料庫檔 | **影響小**。資料可由公開頁面完整還原 |

### 重要觀念

**不該去要那些 ASP 原始碼。**
Classic ASP 綁死在老舊 Windows 主機上，維護商越來越少、資安風險高、無法上 CDN、
行動裝置體驗差、SEO 表現落後。繼續沿用等於把問題從一家廠商轉移到另一個技術債。

正確做法是：**用自有的文字與圖片資產，以現代技術重建一個功能等價、外觀一致、
且公司完全掌握的新網站。**

## 四、法律面

依台灣《著作權法》第 12 條：出資聘人完成之著作，若契約未特別約定，
**著作權原則上歸屬受聘人（即網路公司）**，出資人僅取得利用該著作之權利。

因此：

- ❌ 「要求交出程式原始碼」在法律上不一定站得住腳（須視當初合約而定，請調閱原始合約）
- ✅ **網站上的公司簡介文字、產品說明、產品照片、商標、聯絡資訊皆屬貴公司資產**
- ✅ 使用上述自有內容重建一個全新網站，完全合法、無爭議

**建議路線：不碰對方的程式碼，改為重寫。** 這條路在法律上最乾淨，
技術上也更好，且一次解決技術債。

## 五、建議技術方案

**Astro 靜態網站產生器**（已選定）

| 優點 | 說明 |
|---|---|
| 零主機費用 | 可免費部署於 Cloudflare Pages / Vercel / GitHub Pages |
| 速度極快 | 編譯為純靜態 HTML，無資料庫查詢延遲 |
| 幾乎零維運 | 沒有後端、沒有資料庫，不會被入侵、不需要打安全更新 |
| SEO 佳 | 靜態頁面對搜尋引擎最友善，優於現行 ASP 站 |
| 完全自主 | 原始碼全部在貴公司的 Git 儲存庫中 |
| 好找接手 | 標準開源技術，任何前端工程師都能接手 |

產品資料將存為結構化檔案（Markdown / JSON），未來若需要讓非技術同仁自行上稿，
可再接上輕量後台（如 Decap CMS / Sveltia CMS），一樣免費且不需要伺服器。

### 詢價車功能

現行 `inquiry_list.asp` 的詢價車，在靜態站上可用瀏覽器端暫存 + 表單服務
（如 Formspree / Cloudflare Workers）實作，體驗相同且不需要後端主機。
