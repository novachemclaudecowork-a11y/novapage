# 產品攝影建議

記錄目前產品照的問題、改善方向，以及各產品建議拍攝的內容。

---

## 目前的狀況

| 項目 | 現況 | 問題 |
|---|---|---|
| 尺寸 | 多數 380×285，最小 250×187 | 網站產品頁顯示到 420px 寬，高解析螢幕需要 **840px**，目前是被放大所以糊 |
| 背景 | 灰色漸層為主 | 與感光乳劑那張的白底不一致，排在一起顯得雜亂 |
| 文字 | 紅字燒在圖上 | Google 讀不到；手機上看不清；與旁邊已顯示的品名重複 |
| 浮水印 | 公司名與 logo 燒在圖上 | 自家網站上沒有必要，只是視覺雜訊 |
| 主體 | 三個不同大小的鐵罐 | 每個系列長得一樣，看不出差別 |

目前**最好的一張是高解度感光乳劑**（白底、看得到實際標籤），可作為標準。

---

## 核心觀念

問題不只是「罐子都一樣」，而是**密封的罐子本身就傳達不了客戶要的資訊**。

客戶是網印廠的老闆或生產主管，他要知道的是：

> 這個墨印在我的尼龍布上會不會掉？印出來什麼質感？有哪些顏色？

罐子的外觀回答不了這些。所以**把罐子拍漂亮的效益有限，拍印出來的結果才是重點**。

## 建議的拍攝內容

### 第一優先：印刷成品

| 產品 | 建議拍攝 |
|---|---|
| PU彈性網印油墨 | 印在尼龍布上，**用手拉扯**展示彈性不龜裂 |
| PD金屬玻璃網印油墨 | 印在金屬板、玻璃片上，拍出反光質感 |
| TI布熱轉印油墨 | 印好的 T 恤，可拍轉印前後對照 |
| 410 刮刮樂網印油墨 | 一張刮到一半的刮刮卡 |
| CW水性油墨 | 印在棉布／T/C 混紡上，柔軟手感特寫 |
| PET商標貼紙油墨 | 實際的商標貼紙成品 |
| OT耐噴砂網印油墨 | 噴砂前後對照，展示遮蔽效果 |
| CP通用色膏 | 調色卡／色票，攤開的一整排顏色 |
| 金銀漿、中細閃、螢光粉 | 金屬光澤、閃粉顆粒、螢光在暗處發光 |
| 高解度感光乳劑 | 製版完成的網版，對著光看得到細線條 |
| 刮刀／刮膠 | 不同硬度與形狀並排，尺規入鏡 |
| 各式洗版劑、除墨劑 | **使用前後對照**（髒網版 → 洗乾淨） |

> 清潔類產品用「前後對照」特別有效，那是最直接的效果證明。

### 第二優先：統一規格的產品照

降為輔助用途：純白背景、**不要任何文字與浮水印**、看得到產品標籤
（標籤上有型號與規格，那才是有用的資訊）、至少 1200px、
**所有產品同一角度與距離**。

### 第三優先：包裝規格

「1kg / 4kg / 18kg」這類資訊，**一張共用的尺寸對照圖就夠**，
不需要每個產品各拍一次。

## 拍攝作法（手機即可）

1. 窗邊、陰天或有散射光時拍攝，**不要開閃光燈**
2. 背景用 A2 白色珍珠板或西卡紙，折成 L 型當背景與桌面
3. 另一塊白板放在陰影側當**反光板**補暗部
4. 手機架小腳架，**先把鏡頭擦乾淨**（最容易忘，也最影響清晰度）
5. **每個產品用同樣的角度與距離**——這是讓整站看起來專業的關鍵
6. 拍完**保留原始檔**，不要只留壓縮過的版本

應用照更簡單：把印好的成品拿到窗邊白紙上拍特寫即可。

外包時只要給三個要求：**白底、無文字、固定角度**，再附上上方的拍攝清單。

## 過渡方案：設計圖

在拍到實際成品照之前，可以先用設計圖。
已完成 PU 與 PD 兩個系列共四張，見 [`../design/`](../design/)。

設計圖分為**應用圖**（呈現材質與特性）與**規格圖**（網目、乾燥、稀釋劑等）。
規格圖即使日後有了實拍照也建議保留，因為那類資訊照片取代不了。
