# 產品圖設計稿

這裡存放產品圖的設計稿與成品，**目前尚未使用在網站上**，供日後參考與延用。

> ⚠️ 這個目錄**不在 `public/` 底下，因此不會出現在網站上**。
> 要正式使用時，從後台的「產品照片」上傳即可。

---

## 為什麼要做這些圖

舊站的產品照都是同樣的鐵罐，只有燒在圖上的紅字不同。問題在於：

| 問題 | 說明 |
|---|---|
| 每個系列長得一樣 | 客戶看不出 PU 和 PD 的差別 |
| 字燒在圖上 | Google 讀不到，對搜尋沒幫助；手機上也看不清 |
| 密封的罐子沒有資訊 | 回答不了「印在我的材質上會不會掉」這個真正的問題 |
| 背景不一致 | 灰底與白底混雜，排在一起很亂 |

所以設計上分成兩種圖，各自回答不同的問題。

---

## 兩種圖的分工

### 應用圖 —— 回答「這個墨能印在什麼上、效果如何」

把該系列最關鍵的特性畫出來：

- **PU 彈性油墨**：左邊原狀、右邊實際畫得更寬，印上去的圖案跟著橫向拉開，
  直接呈現「印膜隨布料延展而不龜裂」
- **PD 金屬玻璃油墨**：金屬、玻璃、木材三種素材並排，並標出
  **8:2 兩液型配比**——那是 PD 與其他系列最大的不同

### 規格圖 —— 回答「怎麼用」

把網目、乾燥方式、稀釋劑、洗版劑、特性整理成一眼可掃的卡片。

這類資訊**照片取代不了**，因此即使日後拍到真實的印刷成品照，
規格圖仍建議保留。

---

## 設計規範

沿用這套規範，其他產品的圖才會看起來像同一套型錄。

| 項目 | 設定 |
|---|---|
| 尺寸 | 1200×900（4:3），輸出 1.5 倍為 1800×1350 |
| 背景 | 純白 |
| 主色 | `#203c8a`（與網站一致） |
| 字型 | Noto Sans TC |
| 版面 | 上：系列代號＋品名＋產品編號／中：主視覺／下：藍線＋一句重點＋補充 |
| **不放** | 公司名、浮水印、與品名重複的文字 |

最後一項值得強調：**產品名稱在網站上已經顯示在圖片旁邊了**，
圖上再寫一次只會佔空間，而且搜尋引擎讀不到圖裡的字。

## 怎麼修改與重新產生

```bash
npm install          # 第一次需要，會取得字型與 Playwright
npm run design       # 重新產生 product-images/ 底下的 PNG
```

- 設計稿：[`source/cards.html`](source/cards.html)　每張圖是一個 `.card` 區塊
- 產生程式：[`source/render.mjs`](source/render.mjs)　`CARDS` 物件決定要輸出哪些、檔名為何

### 要新增其他產品的圖

1. 在 `cards.html` 複製一個現有的 `.card` 區塊，改 `id`
2. 換掉系列代號、品名、產品編號與規格數字
   （規格請照抄 `content/products.json` 裡該產品的說明，不要自己填）
3. 在 `render.mjs` 的 `CARDS` 加一行對應
4. 執行 `npm run design`

可直接沿用的樣式：

| 類型 | CSS 類別 |
|---|---|
| 布料 | `.nylon` |
| 金屬 | `.metal` |
| 玻璃 | `.glass` |
| 木材／烤漆 | `.wood` |
| 規格卡片 | `.spec`（`.hl` 加重點色、`.wide` 跨兩欄） |

## 待討論

這些是設計時未定的項目，日後採用前值得先確認：

- **PU 應用圖的布料顏色與印刷顏色**（目前深灰藍底、黃色印刷）是暫定的，
  改成貴公司實際常印的配色會更有說服力
- **PD 應用圖的素材選擇與順序**（金屬／玻璃／木材烤漆）可依主力市場調整
- 是否需要其他語言版本

---

## 長期建議

這套設計圖適合作為**過渡方案**，現在就能讓網站比舊站好看許多。

但真實的印刷成品照仍然最有說服力——客戶想看的是「這個墨印在我的布上長什麼樣」。
折衷做法是：**規格圖長期保留，應用圖等有機會拍到實際成品再替換**。

拍攝的注意事項與各產品建議的拍攝內容，見 [`../docs/產品攝影建議.md`](../docs/產品攝影建議.md)。
